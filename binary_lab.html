Counting up

Add 1 over and over and watch which bits change. Counting in binary works like a car odometer, except each digit only goes from 0 to 1 before it rolls over.

0
 

    Missions

    • With 4 bits, count from 0 up to 8. How many bits flipped on the step from 7 to 8?
    • Keep adding 1 until the counter runs out of room. That is called an overflow.
    • Switch to 5 bits and count past 16. How far can 5 bits go?

    Every bit you add doubles how many values you can store. That is why 8 bits gives 256 values but 16 bits gives 65,536.

    Adding

    You add binary numbers the same way you add regular ones: one column at a time, starting on the right, carrying when a column gets too big. Tap the answer boxes to switch them between 0 and 1. Tap the small boxes on top to write down your carries.

    The only four rules you need

    0 + 0 = 00 + 1 = 11 + 1 = 10
    write 0, carry 1    1 + 1 + 1 = 11
    write 1, carry 1

    Secret messages

    The same bits can stand for letters instead of numbers. A code called ASCII gives every character a number: A is 65, B is 66, and so on. Flip the bits to spell the word, one letter at a time.

    Pixel painter

    A picture is a grid of pixels, and each pixel is stored as bits. With 1 bit per pixel, 0 means white and 1 means dark, so every row of this 8×8 picture is just an 8-bit binary number. This is how sprites are stored in MakeCode Arcade.

      Missions

      • Decode puzzle 1: draw the picture its binary rows describe.
      • Decode puzzle 2.
      • Switch to 2 bits per pixel and paint with all four colors.
      • Answer the question below.
      Each pixel with 2 bits can be one of 4 colors (00, 01, 10, 11). With 3 bits per pixel, how many colors could each pixel be?

      Hex codes

      Long strings of bits are hard to read, so programmers split them into groups of 4. Each group of 4 bits can be 0 through 15, and gets one hexadecimal digit: 0–9, then A through F for 10 through 15.
